# Global System — fictional concept website

Next.js demonstration with synthetic imagery, fictional robot presenters and placeholder contact details. The contact form does not send or store data. Technology names are illustrative; no affiliation or customer results are implied.

## Run locally

Double-click run.bat, or use npm ci and npm run dev. Next.js selects another port if the default is occupied.

## Checks

npm run lint
npm run build

## Pages

Home, Why Us, EDI Services, NPO Services, CLEO Support, Innovation Lab, Webinar demo and Contact demo. The former gallery redirects to Innovation Lab; former photo albums are removed.

## Assets

Robot portraits and team illustrations are AI-generated. The monochrome brand assets are SVG. No original employee, event or speaker photographs are included.
